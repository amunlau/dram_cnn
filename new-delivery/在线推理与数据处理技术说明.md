## 1. 部署后如何在线推理与判定

### 1.1 判定公式

对服务器 `sid`、锚点时刻 t：

> **ŷ = 𝟙[ p_θ(y=1 | X(sid,t)) ≥ τ ]**

- X(sid,t)：与训练相同规则构造的输入张量（默认形状 [31, 128, 32]）
- p_θ：模型 Softmax 后的**正类概率**
- τ：验证集搜索得到的部署阈值（如 `best_threshold.json` / `delivery/model/deploy_threshold.json`）

### 1.2 推荐在线步骤

1. **定锚点 t**：常用业务当前时刻；特征只用 [t−W, t)（半开），默认 W=H=300 秒。
2. **取 mcelog**：该 sid、窗内、且通过错误类型过滤（spatial 默认 error_type∈{1,2}）的 CE；需 row/col/bankid。
3. **构热图**：分箱 + Bank 计数 + log1p；台账默认拼成额外 15 通道 → C=31（见第 3、7 节）。
4. **归一化**：必须用训练集拟合的 `normalization_stats.json`，禁止在线重估。
5. **前向**：`eval()`、关 Dropout；输出 logits → Softmax → p = Softmax(logits)<sub>1</sub>。
6. **判定**：p≥τ → 告警（ŷ=1），否则 ŷ=0。

### 1.3 数值小例

W=H=300，t=72000；归一化后 logits=[1.2, 2.0] → p≈0.69；若 τ=0.64，则 ŷ=1。

### 1.4 检查清单

| 检查项 | 原因 |
|--------|------|
| W/H、错误类型过滤一致 | 避免特征分布漂移 |
| C/H/W 与模型一致 | 形状/语义正确 |
| 训练集归一化统计量 | 尺度与训练对齐 |
| eval + 关闭 Dropout | 推理行为稳定 |
| τ 来自验证集制品 | 保持标定的 P/R |

离线对照实现：`src/dram2cnn/engine/predictor.py`。

## 2. 三类锚点如何生成（含例子）

索引 CSV 通常仅两列：`sid`, `predict_time`。构建时用工单控制采样；正式 y 在预处理再算。

### 2.1 正样本区（期望 y=1）

对每个故障时刻 ft，在闭区间 **[ft−H, ft]** 按步长 `positive_sample_interval_seconds`（默认 60s）取点。

例：ft=72000，H=300 → [71700, 72000] → **6 个点**（71700…72000，**含 ft**）。实现是从左端扫到 ft；默认 H 能被步长整除时与「从 ft 往回推」点集相同。

同一 sid 多个 ft → **多段**正样本区；标签为 [t,t+H] 命中任一 ft 则 y=1。

### 2.2 近故障困难负样本（期望 y=0）

区间 **[ft−prefault, ft−H)**，步长默认 300s。例：prefault=3600 → [68400, 71700)，如 68400…71400。距故障近但仍 y=0，用于抑制过简负样本。

### 2.3 全局负样本（期望 y=0）

在合法界 **[t<sub>min</sub>+W, t<sub>max</sub>−H]** 均匀/随机采样，逼近目标正例比 ρ。

过滤：

1. 跳过会打成 y=1 的点（`_is_positive_at`）
2. `exclude` 掉工单驱动候选的**精确** (sid, predict_time)

**不是**挖空整段近故障时间窗；网格错位时全局点仍可能落在近故障时段内。负样本不足时从 near_neg **补齐**。合并后去重打乱。

目标负样本数：n<sub>−</sub> = round(n<sub>+</sub>·(1−ρ)/ρ)，再与 n<sub>+</sub>、max_rows 规则取 max（见 `index_builder.build_index_dataframe`）。

详情：`docs/data_processing_guide.md` §3.5.2。

## 3. 空间热图如何构建（含常见误解）

### 3.1 一张图对应什么

**一张热图 = 一个 (sid, t) 样本**，不是整机一生一张，也不是每根 DIMM 一张。

默认 X ∈ ℝ<sup>31×128×32</sup>：通道 0–15 = Bank CE 密度；16–30 = 台账 one-hot 平铺（默认开启）。

### 3.2 构造步骤

1. 取窗 [t−W, t) 内 CE  
2. rowbin=⌊row/1024⌋，colbin=⌊col/32⌋ → 128×32  
3. 按 bankid 累加计数，再 log1p  
4. （默认）将该 sid 的 15 维 inventory **复制到每个格子**后拼接

### 3.3 对应关系

- **SID**：只取该机日志与台账；不同 sid 不串台；同一 sid 不同 t 有多张不同热图。  
- **DIMM_number**：inventory 里是整机条数**档位**（8/12/16/24），不是槽位坐标，**不**决定格子位置。  
- **memoryid**：默认 spatial 路径**不**用来分层画图。  
- **工单**：只决定 y，不画进 X。

### 3.4 误解对照

| 误解 | 正确 |
|------|------|
| 每个 DIMM 一张热图 | 否；按 Bank + 地址分箱 |
| 一张图=整机全生命周期 | 否；仅窗口 W 秒 |
| DIMM 决定格子 | 否；row/col 决定 |
| 台账各格不同 | 否；拼通道时整图常数 |

## 4. 空窗样本处理

**空窗**：窗内无合格 mcelog → CE 通道全零（台账通道仍可非零）。

| 配置 | 默认 | 行为 |
|------|------|------|
| `drop_empty_mcelog_windows` | true | 启用丢弃逻辑 |
| `drop_empty_positive_windows` | false | 正空窗是否也丢 |

**原则（默认）**：

- **负 + 空窗 → 丢弃**（无信息负类，易捷径学习）  
- **正 + 空窗 → 保留**（正类稀缺；真实截断可能发生）  
- 工程模式可把正空窗也丢掉

剔除发生在**预处理**，在切分与训练之前。清单字段：`n_empty_grids_dropped`、`n_empty_positive_dropped`、`n_empty_grids_kept_positive`。

## 5. 超参数分层说明

| 层次 | 代表项 | 含义 |
|------|--------|------|
| 任务窗口 | W, H, `label_failure_types` | 预测什么、看多远 |
| 索引采样 | 正/负步长、prefault、ρ、uniform/random | 采哪些锚点 |
| 网格/预处理 | 分箱、Bank 数、空窗开关、归一化、切分 | 如何成 X/y |
| 网络 | in_channels/H/W、通道列表、blocks、dropout、**head_bias** | 容量与结构 |
| 优化 | lr、batch、epochs、patience、early_stop_metric | 怎么训 |
| 不平衡 | weight_scheme、cap、oversample、focal_gamma | 稀有正类 |
| 阈值 | objective、网格 min/max/step | 部署工作点 τ |

默认细节见 `configs/data.yaml`、`model.yaml`、`train.yaml`；`head_bias` 默认 true，nobias 交付实验为 false。

## 6. 类别加权是在空窗剔除之后吗？

**是。** 因果链：

1. 索引可能含空窗  
2. 预处理按第 4 节剔除  
3. 切分得 `y_train`  
4. `compute_class_weights_tensor(y_train)` 统计 P、N（**过采样前**）  
5. 加权交叉熵只作用在已保留样本上  

默认 `weight_scheme=sqrt`：w<sub>−</sub>=1，w<sub>+</sub>=min(√(N/P), cap)，cap 默认 30。  
`positive_oversample_factor` 只加长训练索引；**不重算** class weight，避免双重放大。

验证/测试指标与 τ 搜索**不用**类别权重。

## 7. 台账两种输入方式

编码：固定 15 维 one-hot（型号 7 + DIMM 档 4 + 厂商 4）。

### 方式 A（默认）：拼入热图通道

- `inventory_as_grid_channels=true`，`tabular_dim=0`  
- X = [16 Bank | 15 台账平铺] → **31×H×W**  
- **早期融合**：卷积从第一层起看到硬件类别  
- 空窗时 Bank 全 0，台账通道仍可非零  

### 方式 B：GAP 后独立向量拼接

- `inventory_as_grid_channels=false`，`tabular_dim=15`  
- X 仅 16 通道；另传 tabular [N,15]  
- 池化后投影再与 CNN 向量拼接 → **晚期融合**  
- 与方式 A 的 checkpoint **不兼容**  

在线服务优先与训练配置一致；当前主路径多为方式 A。
