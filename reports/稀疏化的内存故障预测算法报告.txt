\subsection{本文范围、评价口径与总体思路}

本文只讨论 Base-new 上的两条\textbf{相对独立}的后处理实验轨：

\begin{enumerate}
  \item \textbf{FP32 剪枝方法对比}：在同一基线上，对 BN-$\gamma$ 通道剪枝、Filter L1 结构化剪枝、非结构化 L1/L2 幅度稀疏，在比例 $0.10\sim0.80$ 共八档上做短时微调与评估。
  \item \textbf{官方对称 INT8 量化}：在未剪枝的 Base-new 上，先完成批归一化折叠，再以 \texttt{torch.ao.quantization} Eager FakeQuant 做对称有符号 INT8 的 PTQ 与 QAT，并导出无 BN 的 QDQ ONNX、打包 INT8 权重。
\end{enumerate}

两条轨的关系示意如图\ref{fig:report-scope-flow}。本文\textbf{不}把「先剪枝再量化」串成交付流水线，也\textbf{不}讨论融合强制无偏置或自研 AdaRound 整网 INT8 交付包；这样可以把剪枝原理与量化原理各自讲清楚，避免口径混读。

\subsection{结构化通道剪枝}

\subsubsection{基于批归一化尺度参数的通道重要性}

训练期骨干采用「卷积 $\rightarrow$ 批归一化 $\rightarrow$ ReLU」。批归一化对每个通道学习尺度参数 $\gamma$ 与平移参数 $\beta$。对卷积输出某一通道的激活 $z_c$，推理期 BN 可写为
\begin{equation}
  \mathrm{BN}(z_c)=\gamma_c\cdot\frac{z_c-\mu_c}{\sqrt{\sigma_c^2+\varepsilon}}+\beta_c.
\end{equation}
当 $|\gamma_c|$ 很小时，标准化后的特征被整体压低，该通道送入后续卷积的能量弱，往往对下游判别贡献有限。因此可用
\begin{equation}
  s_c = |\gamma_c|
\end{equation}
作为第 $c$ 个输出通道的重要性分数，按设定比例淘汰分数较低的通道，并保留分数较高的通道索引集合 $\mathcal{C}_{\mathrm{keep}}$。该方法对应 Network Slimming 一类工作中「用 BN 尺度做通道选择」的思想。

需要说明两点。第一，本项目全量训练\textbf{并未}对 $\gamma$ 额外施加 L1 稀疏正则，重要性完全来自训练结束后的现成 $\gamma$，属于训练后启发式剪枝，而非「训练期就把通道推稀疏」的完整 Slimming 流程；因此 BN-$\gamma$ 剪枝有效，并不等于训练目标里已经显式鼓励通道稀疏。第二，重要性启发式不是定理：存在 $|\gamma|$ 不大但偶发关键的通道，也存在 $|\gamma|$ 较大却与故障模式弱相关的通道。它之所以仍被广泛使用，是因为计算代价极低、与卷积通道结构天然对齐，并且在大量视觉与工业卷积网络上反复表现稳定，适合作为训练后的第一刀。

与「权重幅度剪枝」相对照：非结构化看的是连接级 $|w|$，通道剪枝看的是通道级 $|\gamma|$。前者挖的是细粒度冗余，后者直接改变张量形状。对内存故障热图这类空间模式相对粗糙、模型容量相对充足的任务，通道级冗余往往先于「所有连接都不可或缺」的假设出现——这也是后文结构化高比例仍接近基线的直观原因。

\subsubsection{Filter L1：不依赖 $\gamma$ 的硬件友好对照}

若部署侧更习惯按卷积滤波器（输出通道对应的一整组卷积核）做结构化裁剪，可采用滤波器权重的 L1 范数
\begin{equation}
  s_c^{\mathrm{filter}} = \big\| W_{c,:,:,:} \big\|_1
\end{equation}
作为重要性。Filter L1 不依赖 BN 是否仍存在、也不依赖训练期是否稀疏化 $\gamma$，因此常作为「硬件友好」的结构化对照。在相同名义剪除比例与相同切片规则下，BN-$\gamma$ 与 Filter L1 得到的\textbf{参数量与理论 GMACs 相同}（因为保留通道数相同），但保留下来的通道集合不同，精度曲线会略有差异——这正是本实验同时报告二者的原因。

\subsubsection{拓扑手术：为什么通道剪枝必须「整层联动」}

只删某一层输出通道、却不改下一层输入通道，卷积核形状将不匹配，网络无法前向。因此结构化剪枝是一次拓扑手术，必须一次完成：

\begin{enumerate}
  \item 当前卷积输出通道切片；
  \item 紧随的 BN（若仍存在）通道切片；
  \item 下一层卷积输入通道切片；
  \item 若剪到接入分类头的特征维，则同步修改第一层全连接的输入维。
\end{enumerate}

这比「把部分权重改成 $0$」重得多，也解释了为何结构化剪枝后几乎总需要短时微调：形状变了，留下的权重需要在新的通道组合下重新对齐决策边界。微调不是重新全量训练，而是用较小学习率做「手术后的康复」。

本实验结构化设定为逐层同比例、\texttt{min\_keep\_channels=8}，且\textbf{未}保护 stem 与末层卷积——即把压缩压力更均匀地分给各 stage，便于观察「通道冗余究竟有多大」。这与部分部署流水线「保护首末层」的保守策略不同；读者在迁移结论时应注意设定差异。

\subsection{非结构化权重稀疏}

\subsubsection{全局幅度稀疏原理}

非结构化稀疏不改变张量几何形状。对卷积与全连接权重，计算每个元素的重要性（L1 用 $|w|$，L2 用 $w^2$），在\textbf{全局}范围内排序，将幅度最低的一部分置零，使零值占比达到目标稀疏度 $\rho$。前向时等价于
\begin{equation}
  \tilde{W} = M \odot W,\qquad M\in\{0,1\}^{\mathrm{dim}(W)},\quad
  \frac{\#\{M=0\}}{\#M}\approx\rho.
\end{equation}
形状不变的好处是：实现简单、与后续逐层量化兼容（零权重量化后仍贴近零点），也便于在同一套推理代码上切换稀疏度。代价是：若运行时仍走稠密卷积，墙钟加速有限，理论 GMACs 乘 $(1-\rho)$ 只是上界估计。

对标量权重，$|w|$ 与 $w^2$ 诱导的排序完全一致，因此 L1 与 L2 在「只按幅度全局剪」时应当得到同一掩码。本实验同时跑两套，正是为了用实测确认这一等价性，而不是宣称多了一种有效算法。

\subsubsection{微调期间必须保持掩码}

非结构化剪枝若在去掉掩码约束后立即用 Adam 微调，被置零的位置可能被优化器重新写回非零，最终落盘模型稀疏率接近 $0$，却仍按名义稀疏度报告理论算力——这会使压缩结论失效。正确流程是：

\begin{enumerate}
  \item 按目标稀疏度生成并注册权重掩码；
  \item 微调阶段前向始终乘掩码（零位置保持为 $0$）；
  \item 微调结束后再固化（移除掩码包装，把零写进权重）；
  \item 用固化后的真实稀疏率刷新统计，再评估与存盘。
\end{enumerate}

本实验全部 $16$ 个非结构化检查点（L1/L2 $\times$ 八档）均满足：存盘稀疏率与目标逐档一致。因此下文非结构化指标对应的是\textbf{真实稀疏模型}。

要点如下：

\begin{itemize}
  \item 相对基线，最差约 $\Delta$F1 $\approx -0.016$（$30\%$ 稀疏），多数档位掉点小于 $0.01$。说明在保持拓扑不变时，权重幅度上也存在可观冗余。
  \item 「最差不一定出现在最高稀疏度」：本实验最差在 $0.30$ 而非 $0.80$。稀疏掩码、微调动力学与阈值重搜共同作用，使曲线不必单调；工程上仍应以扫参表为准，而不是只信单一经验比例。
  \item 理论 GMACs 已按真实稀疏率缩放；但在稠密 GPU 卷积上，延迟未必下降。若目标是墙钟加速且不能上稀疏内核，应优先结构化剪枝。
\end{itemize}

\vspace{1.2em}
\subsection{剪枝综合分析与选型建议}

综合四类方法，可以形成如下判断。

\textbf{（1）通道冗余是主旋律。}
结构化在砍掉一半甚至更多通道后，测试 F1 仍贴近甚至略超 Base-new，说明 GridCNN-Deep 在本故障预测任务上「够用且偏宽」。对部署而言，这是好事：用结构化剪枝换算力，性价比高。

\textbf{（2）精确率与召回率随 $\tau$ 联动，不能孤立解读。}
各档最优 $\tau$ 从约 $0.48$ 到 $0.64$ 不等。同一模型若误用 Base-new 的 $0.78$，容易出现「精确率虚高、召回率被压」的假象。压缩实验必须坚持「各模型自己的验证搜阈」。

\textbf{（3）BN-$\gamma$ 与 Filter L1 是「同宽度、不同通道集合」的一对。}
算力曲线重合，精度曲线接近但非全同。若训练从未稀疏化 $\gamma$，Filter L1 更不依赖该假设；若后续流水线仍保留 BN 并想与 Slimming 叙事对齐，BN-$\gamma$ 更贴切。本实验中二者在 $0.50\sim0.70$ 都表现稳健。

\textbf{（4）非结构化给出精度上界，不自动给出速度。}
在真实稀疏已保证的前提下，它告诉我们：就算不改形状，仍可去掉大量小幅度权重而大体保持 F1。若产品形态需要「形状不变 + 可稀疏存储」，它有价值；若产品形态是通用稠密加速器，应把结构化放在前面。

\textbf{（5）关于「剪完 F1 略升」的理解。}
表中出现高于 Base-new 的 F1，不应解读为「剪枝算法提高了模型上限」。更合理的解释是：短时微调改变了概率校准与边界形状，验证网格搜阈又在新的分数分布上重新选点；在不平衡分类里，F1 对阈值敏感，零点几个百分点的上下波动属于正常现象。真正有工程意义的，是精度仍落在可接受带内的同时，宽度与理论算力被实质性削减。

\textbf{（6）实用建议（仅针对本 Base-new 设定）。}
\begin{enumerate}
  \item 追求稠密算子即可加速：优先 Filter L1 或 BN-$\gamma$，比例可先看 $0.50\sim0.70$。
  \item 需要形状不变的稀疏存储：非结构化 $0.40\sim0.70$ 精度多可用，但要确认推理栈是否吃得到稀疏。
  \item 无论哪种，评估时使用该模型自己的验证 $\tau$，并同时记录 P/R，避免只看 F1。
  \item 若后续要接整数推理，结构化剪枝应发生在 BN 折叠之前或与折叠策略一致地定义通道，否则「按 $\gamma$ 选通道」与「折叠后只剩融合卷积」会语义错位。
\end{enumerate}

\vspace{1.2em}
\subsection{量化：对称有符号 INT8 的原理与约束}

剪枝改变「还有哪些参数」，量化改变「参数与激活用多少比特表示」。本节在\textbf{未剪枝}的 Base-new 上讨论官方 Eager 量化路径，使数值格式问题与结构剪枝问题解耦。

\subsubsection{对称有符号 INT8 与 FakeQuant 仿真}

量化把连续取值映射到有限码字。对张量 $x$，对称有符号 8 比特量化（零点为 $0$）可写为
\begin{equation}
  \hat{x} = s\cdot \mathrm{clip}\Big(\mathrm{round}\big(x/s\big),-128,127\Big),
  \qquad s=\frac{\max(|x|)}{127}.
\end{equation}
权重与激活均采用 per-tensor 对称 \texttt{qint8} 时，整数域为 $[-128,127]$，零点恒为 $0$。与非对称 \texttt{quint8}（带零点）相比，对称格式少一个零点参数，乘加与偏置重标定更直观，也更符合部分整数加速器「有符号累加」的习惯。代价是：ReLU 之后激活非负，对称格式的负半轴码字理论上用不满，这是为约定简单付出的表达效率折中，而不是实现错误。

FakeQuantize 在训练/校准前向中插入「量化再反量化」，使损失或指标感受到量化噪声，但张量仍以浮点参与自动求导与算子调用。需要特别说明评价语义：

\begin{itemize}
  \item 本实验使用 \texttt{torch.ao.quantization} 的 FakeQuantize：前向在浮点域插入「量化再反量化」的仿真，以估计整数推理的精度损失。
  \item 未将模型 \texttt{convert} 到 FBGEMM 整型算子内核——该后端对激活常要求 \texttt{quint8}，与「激活也对称 signed INT8」的约定冲突。
  \item 因此表中 PTQ/QAT 指标是\textbf{BN 已折叠拓扑上的对称 FakeQuant 仿真结果}；导出的 QDQ ONNX 供后续 ORT/TRT 等再做整型内核映射，而不是已经宣称完成某一特定芯片的 INT8 内核加速。
\end{itemize}

\subsubsection{为何必须先折叠批归一化}

训练图中的 Conv–BN–ReLU，在推理期 BN 使用滑动均值方差，可与卷积合并为等价的「融合卷积 +（可选）偏置 + ReLU」。若量化仍作用在「未折叠、带 BN 的 QAT 融合模块」上，FakeQuant 往往作用在 $\gamma/\sqrt{\sigma^2+\varepsilon}$ 缩放后的权重，计算图里还可能残留 BN 与额外缩放，导致：

\begin{enumerate}
  \item 评估图与真正想部署的「Conv–ReLU」图不一致；
  \item 打包 INT8 权重时，若误用未缩放的 raw 权重去除以「缩放权重」的 scale，则整数权重与 FakeQuant 对象错位。
\end{enumerate}

因此本实验的正确顺序是：

\begin{enumerate}
  \item 在 eval 下用 \texttt{fuse\_modules} 做 BN 折叠，得到 ConvReLU2d 等部署友好模块；
  \item 再插入对称 FakeQuant（stem 与分类末层 Linear 保持 FP32）；
  \item PTQ：仅用训练数据校准尺度；QAT：在折叠后的 FakeQuant 模型上短训；
  \item 冻结 observer 后评估、导出 QDQ ONNX，并打包与 FakeQuant 一致的 INT8 权重；
  \item 校验 ONNX 中 \texttt{BatchNormalization} 节点数为 $0$，且 packed 重构误差可接受。
\end{enumerate}

保护层选择 stem 与分类末层，是常见折中：输入层与 logit 层对量化噪声更敏感，中间层则贡献主要参数量，适合优先整数化。本实验中间可量化层为 $10$ 个折叠卷积块加分类头第一层全连接，共 $11$ 个 INT8 权重层。

\subsubsection{PTQ 与 QAT}

\textbf{PTQ（Post-Training Quantization）}：折叠并插入 FakeQuant 后，在训练集上前向若干 batch，令激活/权重观察者统计动态范围并确定 scale，然后冻结，不再反传。代价低，适合作为第一刀。

\textbf{QAT（Quantization-Aware Training）}：在同样的折叠 + FakeQuant 图上，用较小学习率继续训练若干 epoch，使权重在「模拟量化」的噪声下自适应。本实验为 $20$ epoch、$lr=1\times10^{-4}$、三卡 DDP、batch size $128$，并沿用训练配置中的类别权重与正样本过采样。

二者都改变分数分布，故仍须各自验证重搜 $\tau$。

\subsection{量化结果的分析}

\textbf{（1）PTQ 已足够稳。}
在 BN 折叠后的部署拓扑上，仅校准即可把 F1 掉点压在约 $0.4$ 个百分点，且召回不劣化。对「先要一个可量化基线」的工程目标，PTQ 性价比最高。

\textbf{（2）QAT 未自动更优。}
图\ref{fig:qat-loss}显示训练损失持续下降，但验证搜阈后的测试 F1 并未超过 PTQ。说明「量化感知训练一定涨点」并不成立：学习率、epoch、是否从 PTQ 尺度热启动、以及阈值重搜后的工作点迁移，都会改变结论。本设定下应诚实报告：\textbf{QAT 20 epoch 未带来额外 F1 收益}。

\textbf{（3）体积数字要分清「检查点 / packed / ONNX 文件」。}
FP32 \texttt{.pt} 约 $12$\,MB；INT8 packed 约 $3.1$\,MB，反映权重存储收益；QDQ ONNX 文件仍可能接近浮点体量（含浮点权重张量与 Q/DQ 节点），其意义在于提供可被加速器摄取的图结构，而不是直接以文件字节数宣称已完成 $4\times$ 上板压缩。

\textbf{（4）与剪枝轨的关系。}
量化实验未叠加剪枝，因此表\ref{tab:量化主对比}描述的是「满宽度网络的位宽压缩」。若未来需要同时要宽度与位宽，应在结构化剪枝并微调之后，再对\textbf{剪后拓扑}做同样的 BN 折叠 + FakeQuant；那时阈值、尺度与通道集合都已改变，必须重做校准与搜阈，而不能复用本文 PTQ 的 scale 与 $\tau$。

\vspace{1.2em}
\subsection{总结}

本文围绕 Base-new，系统讨论了稀疏化相关的两类工作：FP32 剪枝对比，以及官方对称 INT8 量化。

在剪枝方面，结构化（BN-$\gamma$ / Filter L1）能在测试 F1 基本不损甚至略升的同时，把理论 GMACs 降到约原来的 $1/4\sim1/6$（视比例而定）；非结构化在真实保持稀疏的前提下，多数档位掉点小于 $0.01$，但加速依赖稀疏内核。评价上必须坚持各模型验证重搜阈值。

在量化方面，先 BN 折叠再对称 FakeQuant 的 PTQ 以约 $0.4$ 个百分点的 F1 代价，把权重存储压到约 $3.1$\,MB，并得到无 BN 的 QDQ ONNX；同设定 QAT 短训未超过 PTQ。指标口径为折叠拓扑上的 FakeQuant 仿真，避免把仿真精度误读为某一后端整型内核的实测加速。

总体而言：若优先「稠密硬件上的算力下降」，结构化剪枝是更直接的杠杆；若优先「位宽与存储」，在折叠后的部署图上做对称 INT8 PTQ 是稳健起点。二者可以后续串联，但串联时必须重新校准与搜阈——压缩改变的不只是文件大小，还有分数分布与最优判决点。
