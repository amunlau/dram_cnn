## 0. 相对 v1 的关键修正

上一轮 `…/quant_official_symint8_ptq_qat_basenew_e20_lr1e-4/` 存在**原理性偏差**：

1. 用 `fuse_modules_qat` 得到未折叠的 `ConvBnReLU2d`，FakeQuant 实际作用在 \(\gamma/\sqrt{var}\) **缩放后的权重**上，图中仍保留 **BN + Div**；
2. `pack` 却用 **raw 权重 / 上述 scale**，与 FakeQuant 对象不一致；
3. ONNX「有 Q/DQ」但并非 BN 已折叠的部署拓扑；易被误解为已可部署 INT8。

**本轮（v2）修正**：

1. **先** `fuse_modules`（eval）做 **BN fold** → `ConvReLU2d`（部署拓扑）；  
2. **再** `prepare_qat` 插入对称 FakeQuant（仅因需挂 weight FakeQuant；PTQ 只校准不反传）；  
3. 评估 / QDQ 导出 / packed 均基于**同一折叠模型**；pack 审计 `round(w/scale)` 与 FakeQuant 重构一致；  
4. 导出后 **强制检查 ONNX 中 `BatchNormalization` 节点数为 0**。

指标语义（写清楚，避免再过声明）：**BN 已折叠的对称 signed INT8 FakeQuant 仿真**；未 `convert` 到 FBGEMM 整型算子（该后端要求激活 quint8，与对称 signed 约定冲突）。ONNX 为**无 BN 的 QDQ 标注图**，可供 ORT/TRT 再整型化。

---

## 1. 结论摘要

1. **PTQ**：test F1 **0.7639**（相对 FP32 0.7679，ΔF1≈**−0.004**），召回持平略升；ONNX **0×BN**，pack 审计 max err ≈**2.8e−4**。  
2. **QAT**（20 epoch，lr=1e-4，3 卡 DDP，折叠后训练）：F1 **0.7525**，本设定下**仍未优于 PTQ**。  
3. **体积**：ckpt ≈**12.19 MB**；packed（11 层 INT8 + stem/末层 FP32）实测 ≈**3.11 MB**（理论 ≈3.09 MB），约 **3.9×**。  
4. PTQ/QAT 各一份 **QDQ ONNX**（各 23 对 Q/DQ，**无 BN**）。

## 6. 讨论

1. **PTQ 仍是性价比最高**：折叠后 FakeQuant 校准即可把掉点压在约 0.4 个 F1 点。  
2. **QAT 未涨分**：折叠后 20ep/1e-4 继续降 train loss，但 val 搜阈后的部署 F1 未超过 PTQ；若再挖可试更小 lr / 更少 epoch / 从 PTQ 尺度热启动。  
3. **与 AdaRound 自研 PTQ 勿混表**：本报告走官方 eager FakeQuant + BN fold，不是 `quantize.sh` 路径。  
4. **诚实边界**：未宣称 FBGEMM/TensorRT 整型内核加速；packed 与 FakeQuant 数值一致，ONNX 为无 BN 的 QDQ 图。

---

## 7. 一句话

v2 在 **BN 折叠后的部署拓扑**上重做官方对称 INT8：**PTQ ΔF1≈−0.004**、packed ≈**3.11 MB**、QDQ ONNX **无 BN** 且 pack 与 FakeQuant 一致；同设定 QAT 20ep 仍未超过 PTQ。
