# GridCNN-Deep「Base-new」FP32 剪枝方法对比报告

**日期**：2026-09-17

**实验范围**：仅剪枝与短时微调后的精度评估；**不包含**卷积–BN 融合、去偏置与 INT8 量化。

## 1. 实验目的与结论摘要

本报告在同一 Base-new 权重上，对比四类剪枝策略在八档剪除/稀疏比例下的测试集表现，并保留未剪枝基线（比例=0）以便计算 ΔF1。

**主要结论：**

1. **结构化通道剪枝（BN-γ / Filter L1）**在短时微调后，多数比例下测试 F1 相对 Base-new 仅有小幅波动（约 ±0.01 内）；在约 **60%** 通道剪除时，BN-γ 与 Filter L1 甚至略高于基线（ΔF1 分别约 **+0.0077 / +0.0058**），同时理论计算量可降至约 **0.21 GMACs**（约为基线 1.21 GMACs 的 17.5%）。
2. **非结构化 L1 / L2** 在各比例下 **测试指标完全一致**（ΔF1=0），符合「对标量权重按 \(|w|\) 与按 \(w^2\) 排序等价」的理论预期；相对基线最大掉点出现在 30% / 70% 稀疏附近（约 −0.025 / −0.023），整体仍可接受。
3. 若目标是 **硬件友好、无需稀疏算子** 的实际加速，应优先采用 **Filter L1 或 BN-γ 通道剪枝**（改变张量形状，标准稠密卷积即可受益）；非结构化稀疏更适合作为理论压缩上界或需稀疏内核时的方案。

### 2.1 方法说明（术语对齐常见模型压缩表述）

| 方法键名 | 中文名称 | 粒度 | 硬件含义 |
|----------|----------|------|----------|
| `bn_channel` | BN-γ 通道剪枝（Network Slimming 剪枝阶段） | 结构化 / 通道 | 按 BN 缩放系数 \(\lvert\gamma\rvert\) 淘汰通道并切片，稠密卷积即可加速 |
| `filter` | Filter L1 结构化剪枝 | 结构化 / 卷积核（输出通道） | 按滤波器权重 L1 范数淘汰通道，同样改变形状 |
| `unstructured_l1` | 非结构化 L1 幅度剪枝 | 权重级稀疏 | 按 \(\lvert w\rvert\) 全局置零；形状不变，加速通常需稀疏内核 |
| `unstructured_l2` | 非结构化 L2 幅度剪枝 | 权重级稀疏 | 按 \(w^2\) 全局置零；与 L1 对标量权重排序等价 |

本轮将 Filter L1 作为「硬件友好」的结构化对照（相对非结构化而言修改小、易落地），**未**额外引入 N:M 细粒度稀疏或块稀疏等需特殊算子的方案。

## 4. 分方法分析

### 4.1 BN-γ 通道剪枝（结构化）

- 通道剪除比例与目标比例接近（例如目标 0.30 时实测通道剪除约 0.30）；因通道衔接，**参数量降幅往往大于通道比例**（例如 30% 通道剪除对应约 50% 参数减少）。
- 高比例（0.70–0.80）下理论 GMACs 可到 0.12 / 0.06 量级，而测试 F1 仍贴近基线，说明在本任务与 10 epoch 微调设定下，BN-γ 重要性排序有效。
- 比例 0.60 时 F1 略升，可能来自：过参数化网络的正则化效应、阈值重搜、以及短时微调在较小网络上更易拟合验证目标。**不宜过度解读为「剪得越多越好」**，应以部署侧 P/R 约束再选点。

### 4.2 Filter L1（硬件友好结构化）

- 与 BN-γ 在相同比例下 **参数量 / 理论 GMACs 相同**（同一套通道切片规则），但保留通道集合不同，故精度曲线不完全重合。
- 多数档位 ΔF1 接近 0 或略正，整体稳定性好，适合作为「少改硬件栈」的默认结构化方案。
- 与 BN-γ 相比：本仓库全量训练 **未** 对 γ 做 L1 稀疏正则，因此 BN-γ 重要性并非 Slimming 论文中的「训时诱导」完整流程；Filter L1 仅依赖卷积核幅度，不依赖 BN 统计，二者可互补对照。

### 4.3 非结构化 L1 / L2

- **实现**：L1 使用全局 \(\lvert w\rvert\)；L2 向 `global_unstructured` 传入 `importance_scores=w²`。对单个标量权重，\(w^2\) 与 \(\lvert w\rvert\) 单调一致，故剪掉的是同一批权重；分目录归档便于审计。
- **精度**：相对结构化，同「名义比例」下掉点略大（最差约 −0.025），且 **理论 GMACs 按 (1−稀疏率) 估算**，实际延迟下降依赖稀疏计算库，稠密 GPU 上往往无明显加速。
- **建议**：若产线只能跑标准稠密卷积，应优先结构化结果；非结构化结果用于压缩率–精度上界分析。

## 5. 思考与建议

1. **选型**：部署友好优先 → **Filter L1 或 BN-γ**，比例可先看 **0.50–0.70**（F1 接近或略优于 Base-new，计算量约降至 26%–10% 量级）。若后续再接量化，建议在选定结构化点上单独开一轮实验（本报告不讨论量化）。
2. **阈值**：各比例最优 valτ 多在 0.48–0.68，与 Base-new 的 0.78 不同；汇报与上线必须使用 **该模型自己的 val 搜阈**，不可混用基线 τ。
3. **L2 实验价值**：本轮实证确认等价性；后续若做「按输出通道 L2 范数」等结构化变体，才与 L1 Filter 形成真正方法差异。
4. **保护策略**：本轮关闭了 stem/末层保护且全部跑通；若迁移到更小宽度网络，高比例时需重新评估 `min_keep_channels` 与保护开关。
