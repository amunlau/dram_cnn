# 量化方法与输出后处理说明

配套：`delivery/bnch040-u30-symint8-20260827/`  
主模型：`model/grid_cnn_w8a8_packed.pt`

## 必须记住

1. **BN-γ 通道剪枝 + 非结构化 30% + 整网对称 signed INT8**（zp=0，域 [-128,127]）  
2. 图内只有 logits；**Softmax 与阈值在图外**  
3. 部署：\(p_1=\mathrm{softmax}(z)[1]\)，\(\hat y=1\) 当 \(p_1 \ge 0.5\)

验收（本包实测）：精确率 **0.9244**，召回率 **0.6394**，F1 **0.7559**。

流水线均为：**BN-γ → 融合无偏置 → 非结构化 30% → 整网 INT8**。  
验收：**精确率 > 0.8 且召回率 > 0.6**。

## 量化语义

对浮点 \(x\)、标量 scale \(s\)：

```text
q = clip(round(x / s), -128, 127)
x_hat = q * s
```

权重、激活均为**逐层一个 scale**，禁止逐通道 / uint8。无偏置。细节参数见 `layer_quant_specs.json`、`input_quant_params.json`。
