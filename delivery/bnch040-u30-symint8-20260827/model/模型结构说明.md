# 模型结构说明（BN-γ 剪通道后 · 整网对称 INT8）

主文件：`grid_cnn_w8a8_packed.pt`  
通道拓扑：`channel_masks.json`（BN-γ=0.40 后保留的输出通道索引）

结构仍为 GridCNN-Deep：**stem → 4 个下采样阶段 → GAP → head.0 / head.3**。  
与未做通道剪枝版本相比：**中间卷积通道数变少**，`head.0` 输入维等于末层卷积输出通道数；请按 masks 重建，勿按原始 `backbone_channels=[64,128,256,256]` 硬编码。

| 项 | 值 |
|----|-----|
| 输入 | `[N,31,128,32]` |
| 输出 | `[N,2]` logits；图外 Softmax；τ=**0.5** |
| 偏置 | 全部无 |
| 量化 | 逐层对称 signed INT8，stem/head.3 均 INT8 |
| 非结构化稀疏 | 约 30%（形状不变） |
| 结构化 | BN-γ 通道剪枝目标 40% |

部署检查：无 bias；全部 `keep_fp32=false`；加载 packed 时应用 `channel_masks`。
