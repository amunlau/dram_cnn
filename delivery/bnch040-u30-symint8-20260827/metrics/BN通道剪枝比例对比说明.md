# BN-γ 通道剪枝比例对比说明

本说明记录本交付包选定 **BN-γ = 0.40** 之前的扫参结果。  
交付目录：`delivery/bnch040-u30-symint8-20260827/`  
训练权重会话：`runs/exp_tianchi_full_f1_nobias_apstop_allint8_ddp/20260827_092834_346804`

---

## 扫参设定

在同一无偏置训练权重上，固定流水线为：

```text
BN-γ 结构化通道剪枝（+微调 5 轮）
  → Conv+BN+ReLU 融合并丢弃偏置
  → 非结构化 L1 30%（+微调 5 轮）
  → 整网逐层对称 signed INT8
```

- BN-γ 在**融合前**执行（重要性来自 `BatchNorm2d.weight`；融合后 BN 已不存在）
- 默认保护 stem / 末层卷积通道
- 验收（测试集、部署 τ）：**精确率 > 0.8 且召回率 > 0.6**
- 扫参比例：0.10 / 0.20 / 0.30 / 0.40 / 0.50

## 选用理由

五档**全部**达标。在此约束下选择 **0.40**：

1. INT8 F1 **最高**（0.7559）  
2. 召回率仍明显高于 0.6（0.6394），精确率 0.9244  
3. 相对仅非结构化交付包（≈3.04 MB），体积降到约 **1.30 MB**  
4. 比 0.50 略大，但 F1 / 召回更稳，避免过度压缩

复现选用比例：

```bash
bash scripts/fuse_prune_quantize.sh \
  configs/experiments/exp_full_f1_nobias_apstop_allint8_ddp.yaml \
  --train-dir runs/exp_tianchi_full_f1_nobias_apstop_allint8_ddp/20260827_092834_346804 \
  --sparsity 0.3 --bn-channel-ratio 0.4 --finetune-epochs 5
```

流水线已支持 `--bn-channel-ratio`。
