# GridCNN 整网 INT8（剪枝后）ONNX 模型结构详细说明

对应文件：同目录 [`grid_cnn_w8a8_pruned_allint8.onnx`](grid_cnn_w8a8_pruned_allint8.onnx)  
权重来源：`delivery/model/grid_cnn_w8a8_packed.pt`（融合无偏置 → 目标约 30% 非结构化剪枝 → **整网 W8A8**）

---

## 1. 模型一句话说明

本 ONNX 实现 **GridCNN-Deep** 的**部署拓扑**：

- 输入为 **31×128×32** 的 CE 空间热图（已预处理归一化）
- 结构：**主干首层 → 4 个下采样阶段 → 全局平均池化 → 两层全连接分类头**
- **无任何偏置（bias）**
- **无独立批归一化层**（训练时 BN 已融合进卷积）
- **无 Dropout**（推理已关闭）
- 源打包模型为 **整网 INT8**（含 stem / head.3，无单精度保护层）
- 本 ONNX 为便于跨框架加载，将 INT8 权重按通道 scale **反量化为 float32** 写入标准算子图；**图内不含激活量化节点**

部署决策阈值：**τ = 0.64**（正类概率 ≥ τ 判为正）

## 3. 数据流（高 × 宽 × 通道）

```text
input
  128×32×31
    │
    ▼
stem：Conv3×3 + ReLU                 → 128×32×64
    │
    ▼
stage0：Conv+ReLU ×2 → MaxPool2×2    → 64×16×64
    │
    ▼
stage1：Conv+ReLU ×3 → MaxPool2×2    → 32×8×128
    │
    ▼
stage2：Conv+ReLU ×3 → MaxPool2×2    → 16×4×256
    │
    ▼
stage3：Conv+ReLU ×2 → MaxPool2×2    → 8×2×256
    │
    ▼
GlobalAveragePool → Flatten            → 256
    │
    ▼
head.0：MatMul + ReLU                  → 256
    │
    ▼
head.3：MatMul                          → 2 (logits)
```

## 4. 逐层规格表

尺寸写法：高×宽×通道。  
卷积一律 **3×3、pads=[1,1,1,1]、strides=[1,1]、dilation=1、group=1、无偏置**；  
池化一律 **kernel=2×2、strides=2×2、pads=0、ceil_mode=0**。

| 层级 | 类型 | 输入 | 输出 | 备注 |
|------|------|------|------|------|
| input | 输入 | — | 128×32×31 | NCHW |
| stem | 卷积+ReLU | 128×32×31 | 128×32×64 | 无偏置 |
| stages.0.net.0 | 卷积+ReLU | 128×32×64 | 128×32×64 | 无偏置 |
| stages.0.net.1 | 卷积+ReLU | 128×32×64 | 128×32×64 | 无偏置 |
| stages.0 MaxPool | 最大池化 | 128×32×64 | 64×16×64 | 2×2 / s=2 |
| stages.1.net.0 | 卷积+ReLU | 64×16×64 | 64×16×128 | 通道倍增 |
| stages.1.net.1 | 卷积+ReLU | 64×16×128 | 64×16×128 | |
| stages.1.net.2 | 卷积+ReLU | 64×16×128 | 64×16×128 | |
| stages.1 MaxPool | 最大池化 | 64×16×128 | 32×8×128 | |
| stages.2.net.0 | 卷积+ReLU | 32×8×128 | 32×8×256 | 通道倍增 |
| stages.2.net.1 | 卷积+ReLU | 32×8×256 | 32×8×256 | |
| stages.2.net.2 | 卷积+ReLU | 32×8×256 | 32×8×256 | |
| stages.2 MaxPool | 最大池化 | 32×8×256 | 16×4×256 | |
| stages.3.net.0 | 卷积+ReLU | 16×4×256 | 16×4×256 | |

## 5. ONNX 图中的算子与权重名

### 5.1 算子统计

| 算子 | 数量 | 说明 |
|------|------|------|
| Conv | 11 | 仅 2 个输入（X, W），**无 bias** |
| Relu | 12 | 11 个卷积后 + head.0 后 |
| MaxPool | 4 | 四个阶段各一次 |
| GlobalAveragePool | 1 | |
| Flatten | 1 | |
| MatMul | 2 | 两层全连接（无偏置，故不是带 C 的 Gemm） |

图中**不出现**：Bias 输入、BatchNormalization、Dropout。

### 5.2 权重初始化器（共 13 个）

| 逻辑层 | ONNX initializer 名 | 形状 | 与源权重关系 |
|--------|---------------------|------|--------------|
| stem | `core.stem.conv.weight` | (64, 31, 3, 3) | 与 Conv 权重同布局 |
| stages.0.net.0 | `core.stages.0.net.0.conv.weight` | (64, 64, 3, 3) | 同布局 |
| stages.0.net.1 | `core.stages.0.net.1.conv.weight` | (64, 64, 3, 3) | 同布局 |
| stages.1.net.0 | `core.stages.1.net.0.conv.weight` | (128, 64, 3, 3) | 同布局 |
| stages.1.net.1 | `core.stages.1.net.1.conv.weight` | (128, 128, 3, 3) | 同布局 |
| stages.1.net.2 | `core.stages.1.net.2.conv.weight` | (128, 128, 3, 3) | 同布局 |
| stages.2.net.0 | `core.stages.2.net.0.conv.weight` | (256, 128, 3, 3) | 同布局 |
| stages.2.net.1 | `core.stages.2.net.1.conv.weight` | (256, 256, 3, 3) | 同布局 |
| stages.2.net.2 | `core.stages.2.net.2.conv.weight` | (256, 256, 3, 3) | 同布局 |
| stages.3.net.0 | `core.stages.3.net.0.conv.weight` | (256, 256, 3, 3) | 同布局 |
| stages.3.net.1 | `core.stages.3.net.1.conv.weight` | (256, 256, 3, 3) | 同布局 |
| head.0 | `onnx::MatMul_47` | (256, 256) | **等于** `W.T`（`W` 为 `nn.Linear` 的 `(out,in)=(256,256)`） |
| head.3 | `onnx::MatMul_48` | (256, 2) | **等于** `W.T`（`W` 为 `(out,in)=(2,256)`） |

全连接计算为：`y = x @ MatMulWeight`，因此 MatMul 权重是 PyTorch `nn.Linear.weight` 的转置。已核对：与 INT8 打包反量化后的 `W.T` **逐元素一致**。

## 6. 与 INT8 打包模型的关系（重要）

| 项目 | 打包 `.pt`（`grid_cnn_w8a8_packed.pt`） | 本 ONNX |
|------|------------------------------------------|---------|
| 拓扑 | 融合 Conv+ReLU，无偏置 | 相同 |
| 权重来源 | 剪枝后 W8A8（整网 INT8） | INT8 权重 × 通道 scale **反量化**为 float32 |
| 存储精度 | int8 + scale | float32 |
| 激活量化 | 推理时按层 `act_in_scale / zp` | **本图无激活量化**（浮点激活通路） |
| 首尾层 | stem / head.3 均为 INT8 | 同样纳入（反量化后写入） |

**如何理解指标差异（全量测试集 5348 条，τ=0.64）：**

| 路径 | F1 | 精确率 | 召回率 |
|------|-----|--------|--------|
| INT8 打包参考推理（含激活量化） | **0.7422** | 0.9856 | 0.5952 |
| 本 ONNX / 反量化浮点通路 | **0.7512** | 0.8600 | 0.6669 |

- 正类概率平均绝对误差约 **0.086**；阈值 0.64 下预测一致率约 **95.2%**
- 差异来自「有无激活量化」，**不是** ONNX 权重导出错
- ONNX 与「同一套反量化权重的 PyTorch 融合模型」logits 最大误差约 **1e-6**，导出数值正确
- 真 INT8 部署请以打包文件 + `delivery/model/layer_quant_specs.json` 为准；本 ONNX 用于结构对齐、联调与浮点参考

**稀疏度说明：**

- 剪枝**目标**稀疏度约 **30%**（非结构化 L1，已达成）
- 经 W8A8 / AdaRound 后，打包 INT8 权重中**精确为 0 的比例约 15.2%**（量化取整后不再等于剪枝刚结束时的 30% 零值比）
- 本 ONNX 反量化权重与打包 INT8 零值位置一致

## 7. 源 INT8 量化参数摘要

激活 uint8 公式：

```text
q = clip(round(x / act_in_scale + act_in_zp), 0, 255)
x̂ = act_in_scale * (q - act_in_zp)
```

权重（按输出通道对称）：`W ≈ scale[oc] * W_int8[oc, ...]`

| 层名 | 类型 | act_in_scale | act_in_zp | 权重 scale 维数 | 权重 scale 范围 | keep_fp32 |
|------|------|--------------|-----------|-----------------|-----------------|-----------|
| `stem` | conv | 0.03590577 | 28 | 64 | 0.000907866 ~ 0.00379865 | false |
| `stages.0.net.0` | conv | 0.016582231 | 0 | 64 | 0.000285729 ~ 0.0011949 | false |
| `stages.0.net.1` | conv | 0.015850288 | 0 | 64 | 1.23078e-05 ~ 0.00134869 | false |
| `stages.1.net.0` | conv | 0.01283463 | 0 | 128 | 0.000255672 ~ 0.00090099 | false |
| `stages.1.net.1` | conv | 0.011487546 | 0 | 128 | 3.77148e-08 ~ 0.000631208 | false |
| `stages.1.net.2` | conv | 0.010158961 | 0 | 128 | 7.87402e-11 ~ 0.000588841 | false |
| `stages.2.net.0` | conv | 0.011849428 | 0 | 256 | 6.47221e-08 ~ 0.000441614 | false |
| `stages.2.net.1` | conv | 0.012770235 | 0 | 256 | 1.66797e-09 ~ 0.000294021 | false |
| `stages.2.net.2` | conv | 0.033545438 | 0 | 256 | 1.47287e-07 ~ 0.000287665 | false |
| `stages.3.net.0` | conv | 0.077712871 | 0 | 256 | 3.62017e-07 ~ 0.000274357 | false |
| `stages.3.net.1` | conv | 0.077550297 | 0 | 256 | 9.747e-07 ~ 0.00019034 | false |
| `head.0` | linear | 0.2003095739 | 0 | 256 | 6.80762e-07 ~ 0.000713283 | false |
| `head.3` | linear | 0.06794509888 | 0 | 2 | 0.000560321 ~ 0.000577822 | false |

完整逐通道 `weight_scale` 见 `delivery/model/layer_quant_specs.json`。

## 8. 输入通道含义

- **通道 0～15**：按 bank 划分的可纠正错误（CE）空间热图  
- **通道 16～30**：硬件库存等属性编码通道  
- 空间分箱后：**高=128、宽=32**  
- 交付数据 `delivery/data/X_*.npy` 已归一化，**勿再标准化**

## 9. 使用示例（Python + ONNX Runtime）

```python
import numpy as np
import onnxruntime as ort

sess = ort.InferenceSession(
    "grid_cnn_w8a8_pruned_allint8.onnx",
    providers=["CPUExecutionProvider"],
)
x = np.load("../data/X_test.npy").astype(np.float32)  # [N,31,128,32]
logits = sess.run(["logits"], {"input": x})[0]
# 稳定 softmax
z = logits - logits.max(axis=1, keepdims=True)
prob = np.exp(z)
prob = prob / prob.sum(axis=1, keepdims=True)
pred = (prob[:, 1] >= 0.64).astype(np.int64)
```

## 10. 实现检查清单

- [ ] 输入 NCHW：`[N, 31, 128, 32]`，float32  
- [ ] 11 个 Conv：3×3 / pad=1 / stride=1 / **无 bias**，后接 Relu  
- [ ] 4 次 MaxPool：2×2 / stride=2  
- [ ] GlobalAveragePool → Flatten → MatMul(256→256) + Relu → MatMul(256→2)  
- [ ] 全连接 MatMul 权重按 **`y = x @ W.T`** 理解（见第 5.2 节）  
- [ ] 输出为 logits，自行 softmax；阈值 **τ=0.64**  
- [ ] 图中无 BatchNorm / Dropout / bias  
- [ ] 若做真 INT8：stem 与 head.3 也要量化；并实现激活量化（本 ONNX 未包含）
