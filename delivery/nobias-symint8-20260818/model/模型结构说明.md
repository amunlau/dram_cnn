# 模型结构说明（部署 · 整网逐层对称 INT8）

对应交付文件：`delivery/nobias-symint8-20260818/model/grid_cnn_w8a8_packed.pt`  
配置快照：`config_snapshot.json`（其中的 `model` 字段）

本文说明网络结构、张量尺寸、无偏置约束，以及**训练时结构**与**部署融合结构**的对应关系。  
**本次交付为整网全 INT8**：主干首层与分类末层均量化，无单精度保护层。  
量化方案：**逐层（per-tensor）对称 signed INT8**，权重与激活 zero-point=0，整数域 `[-128, 127]`；**不是 uint8，不是逐通道量化**。

---

## 1. 一句话概览

**GridCNN-Deep**：将内存可纠正错误（CE）聚合为 **31 通道 × 128×32** 空间热图，经  
**主干首层 → 4 个卷积下采样阶段（含最大池化）→ 全局平均池化 → 两层全连接分类头**，输出 2 类得分。  

交付的 INT8 模型已完成 **「卷积 + 批归一化 + ReLU」融合**，**全部卷积层与全连接层无偏置**，且 **全部权重层为 INT8**。

| 项 | 值 |
|----|-----|
| 结构名称 | `grid_cnn` / GridCNN-Deep |
| 输入 | `[样本数, 31, 128, 32]`，单精度浮点（或按 `input_quant_params.json` 量化的 **signed int8**） |
| 输出 | `[样本数, 2]` 类别得分；正类概率取 softmax 后第 1 维；与阈值 τ 比较得 0/1 |
| 参数量（训练单精度、分类头无偏置） | **3,184,192** |
| 卷积层数 | **11**（主干首层 1 层 + 各阶段共 10 层） |
| 卷积核 | 一律 **3×3**，同尺寸填充（填充=1），步长=1 |
| 批归一化 | 训练时存在；部署时已折进卷积，**不再单独存在批归一化层** |
| 偏置 | **全部为无**；见 `bias_audit.json` |
| 随机失活 | 训练时比例 0.25；**推理必须关闭** |
| 量化 | W8A8 逐层对称 signed INT8；**stem / 全部 stages / head.0 / head.3 均为 INT8**（`keep_fp32=false`） |
| 打包格式 | `gridcnn_w8a8_packed_v3` |

## 2. 数据流示意（部署融合后）

尺寸写法：**高 × 宽 × 通道**（张量内存布局为「样本×通道×高×宽」）。

```text
输入
  128×32×31
    │
    ▼
主干首层：3×3 卷积 + ReLU     → 128×32×64     （INT8，批归一化已融合，无偏置）
    │
    ▼
阶段 0：卷积+ReLU ×2 → 随机失活 → 最大池化
  128×32×64 → 128×32×64 → 64×16×64
    │
    ▼
阶段 1：卷积+ReLU ×3 → 随机失活 → 最大池化
  64×16×64 → 64×16×128 → 32×8×128
    │
    ▼
阶段 2：卷积+ReLU ×3 → 随机失活 → 最大池化
  32×8×128 → 32×8×256 → 16×4×256
    │
    ▼
阶段 3：卷积+ReLU ×2 → 随机失活 → 最大池化
  16×4×256 → 16×4×256 → 8×2×256
    │
    ▼
自适应全局平均池化(1×1)       → 1×1×256 → 展平 → 256
    │
    ▼
全连接 256→256 + ReLU + 随机失活   （INT8）
    │
    ▼
全连接 256→2                  → 类别得分（INT8）
```

## 4. 与打包文件中的层名对应

| 打包层名 | 含义 | 量化策略 |
|----------|------|----------|
| `stem` | 主干首层：卷积 + ReLU | **INT8（逐层对称 signed）** |
| `stages.0.net.0` / `.1` | 阶段 0 | INT8 |
| `stages.1.net.0` / `.1` / `.2` | 阶段 1 | INT8 |
| `stages.2.net.0` / `.1` / `.2` | 阶段 2 | INT8 |

## 5. 训练时结构与部署结构（重要）

| | 训练时（含批归一化） | 交付部署（本包） |
|--|---------------------|------------------|
| 基本块 | 卷积（无偏置）→ 批归一化 → ReLU | 卷积（无偏置）→ ReLU（批归一化已折进权重） |
| 批归一化折合偏置 | 批归一化的平移项等有效 | **已丢弃** |
| 全连接 | 无偏置 | 同左 |
| 随机失活 | 训练开启 | **关闭** |
| 权重精度 | 单精度 | **全部 INT8（逐层对称，signed）** |

## 6. 输入通道含义（简要）

- **通道 0～15**：按 bank 划分的可纠正错误空间热图（共 16 路）  
- **通道 16～30**：硬件库存等属性铺成的编码通道（共 15 路）  
- 空间：按行/列分箱后为 **高=128、宽=32**  

交付的 `data/X_*.npy` 已完成预处理与归一化，**请勿再标准化**。详见上级 [`../README.md`](../README.md) 第 3 节。

## 7. 输出与阈值

1. 前向得到类别得分，形状为 `[样本数, 2]`  
2. 正类概率 = softmax 后第 1 维  
3. 预测 =（概率 ≥ τ）；交付部署阈值见 `deploy_threshold.json`（本包为 **0.56**）

FP32 训练权重来自验证集搜阈 F1 的第 **2** 轮最优（patience=50，训练至第 52 轮才停）。这不是「只训了 2 轮」；见 [`../evidence/notes/训练早停与第2轮最优说明.md`](../evidence/notes/训练早停与第2轮最优说明.md)。

## 8. 部署实现检查清单

- [ ] 输入形状为 `[样本数, 31, 128, 32]`  
- [ ] 11 个卷积全部为 **3×3 / 填充=1 / 步长=1 / 无偏置**，后接 ReLU  
- [ ] **stem 与 head.3 均为 INT8**（不是单精度）  
- [ ] 权重与激活均为 **对称 signed INT8**（zp=0，值域 -128～127），**不是 uint8、不是逐通道**  
- [ ] 4 次 **2×2、步长=2** 最大池化  
- [ ] 全局平均池化 → 256 维 → 全连接(256→256)无偏置 → ReLU → 全连接(256→2)无偏置  
- [ ] 推理关闭所有随机失活  
- [ ] 不加载、不累加任何偏置向量  
- [ ] INT8 层使用 `layer_quant_specs.json` 中的**标量**缩放（每层一个 scale）
