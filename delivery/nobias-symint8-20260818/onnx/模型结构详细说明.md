# GridCNN 整网逐层对称 INT8（剪枝后）ONNX 模型结构详细说明

对应文件：同目录 [`grid_cnn_w8a8_pruned_allint8.onnx`](grid_cnn_w8a8_pruned_allint8.onnx)  
权重来源：`delivery/nobias-symint8-20260818/model/grid_cnn_w8a8_packed.pt`（融合无偏置 → 目标约 30% 非结构化剪枝 → **整网逐层对称 signed INT8**）

---

## 1. 模型一句话说明

本 ONNX 实现 **GridCNN-Deep** 的**部署拓扑**：

- 输入为 **31×128×32** 的 CE 空间热图（已预处理归一化）
- 结构：**主干首层 → 4 个下采样阶段 → 全局平均池化 → 两层全连接分类头**
- **无任何偏置（bias）**
- **无独立批归一化层**（训练时 BN 已融合进卷积）
- **无 Dropout**（推理已关闭）
- 源打包模型为 **整网 INT8**（含 stem / head.3，无单精度保护层）
- 本 ONNX 为便于跨框架加载，将 INT8 权重按**逐层标量** scale **反量化为 float32** 写入标准算子图；**图内不含激活量化节点**

部署决策阈值：**τ = 0.56**（正类概率 ≥ τ 判为正）

FP32 训练源权重的验证搜阈 F1 最优在第 **2** 轮（`patience=50`，第 **52** 轮早停）。这不是「只训了 2 轮」；见 [`../evidence/notes/训练早停与第2轮最优说明.md`](../evidence/notes/训练早停与第2轮最优说明.md)。

## 3. 数据流（高 × 宽 × 通道）

```text
input
  128×32×31
    │
    ▼
stem：Conv3×3 + ReLU                 → 128×32×64
    │
    ▼
stage0：Conv+ReLU ×2 → MaxPool2×2    → 64×16×64
    │
    ▼
stage1：Conv+ReLU ×3 → MaxPool2×2    → 32×8×128
    │
    ▼
stage2：Conv+ReLU ×3 → MaxPool2×2    → 16×4×256
    │
    ▼
stage3：Conv+ReLU ×2 → MaxPool2×2    → 8×2×256
    │
    ▼
GlobalAveragePool → Flatten            → 256
    │
    ▼
head.0：MatMul + ReLU                  → 256
    │
    ▼
head.3：MatMul                          → 2 (logits)
```

## 4. 逐层规格表

尺寸写法：高×宽×通道。  
卷积一律 **3×3、pads=[1,1,1,1]、strides=[1,1]、dilation=1、group=1、无偏置**；  
池化一律 **kernel=2×2、strides=2×2、pads=0、ceil_mode=0**。

| 层级 | 类型 | 输入 | 输出 | 备注 |
|------|------|------|------|------|
| input | 输入 | — | 128×32×31 | NCHW |

| stages.0.net.0 | 卷积+ReLU | 128×32×64 | 128×32×64 | 无偏置 |
| stages.0.net.1 | 卷积+ReLU | 128×32×64 | 128×32×64 | 无偏置 |
| stages.0 MaxPool | 最大池化 | 128×32×64 | 64×16×64 | 2×2 / s=2 |
| stages.1.net.0 | 卷积+ReLU | 64×16×64 | 64×16×128 | 通道倍增 |
| stages.1.net.1 | 卷积+ReLU | 64×16×128 | 64×16×128 | |
| stages.1.net.2 | 卷积+ReLU | 64×16×128 | 64×16×128 | |

| stages.2.net.0 | 卷积+ReLU | 32×8×128 | 32×8×256 | 通道倍增 |
| stages.2.net.1 | 卷积+ReLU | 32×8×256 | 32×8×256 | |

## 6. 与 INT8 打包模型的关系（重要）

| 项目 | 打包 `.pt`（`grid_cnn_w8a8_packed.pt`） | 本 ONNX |
|------|------------------------------------------|---------|
| 拓扑 | 融合 Conv+ReLU，无偏置 | 相同 |
| 权重来源 | 剪枝后 W8A8（整网逐层对称 INT8） | INT8 权重 × **逐层标量** scale **反量化**为 float32 |
| 存储精度 | int8 + scale | float32 |
| 激活量化 | 推理时按层 `act_in_scale`（zp=0） | **本图无激活量化**（浮点激活通路） |
| 首尾层 | stem / head.3 均为 INT8 | 同样纳入（反量化后写入） |

**如何理解指标差异（全量测试集 5348 条，τ=0.56）：**

| 路径 | F1 | 精确率 | 召回率 |
|------|-----|--------|--------|
| INT8 打包参考推理（含激活量化） | **0.7488** | 0.9375 | 0.6233 |
| 本 ONNX / 反量化浮点通路 | **0.7673** | 0.8647 | 0.6897 |

- 正类概率平均绝对误差约 **0.0659**；阈值 0.56 下预测一致率约 **96.3%**
- 差异来自「有无激活量化」，**不是** ONNX 权重导出错
- ONNX 与「同一套反量化权重的 PyTorch 融合模型」logits 最大误差约 **1e-06**
- 真 INT8 部署请以打包文件 + `delivery/nobias-symint8-20260818/model/layer_quant_specs.json` 为准；本 ONNX 用于结构对齐、联调与浮点参考

**稀疏度说明：**

- 剪枝**目标**稀疏度约 **30%**（非结构化 L1，已达成）
- 经 W8A8 / AdaRound 后，打包 INT8 权重中**精确为 0 的比例约 32.1%**（量化取整后不再等于剪枝刚结束时的 30% 零值比）
- 本 ONNX 反量化权重与打包 INT8 零值位置一致

## 7. 源 INT8 量化参数摘要

激活 **对称 signed INT8** 公式（**不是 uint8**）：

```text
q = clip(round(x / act_in_scale), -128, 127)
x̂ = act_in_scale * q
```

权重（**逐层一个 scale**，不是逐通道）：`W ≈ scale * W_int8`

| 层名 | 类型 | act_in_scale | act_in_zp | 权重 scale 维数 | 权重 scale | keep_fp32 |
|------|------|--------------|-----------|-----------------|------------|-----------|
| `stem` | conv | 0.064220256 | 0 | 1（逐层标量） | 0.0031175707 | false |
| `stages.0.net.0` | conv | 0.033054187 | 0 | 1（逐层标量） | 0.0012087348 | false |
| `stages.0.net.1` | conv | 0.037274819 | 0 | 1（逐层标量） | 0.00095211749 | false |
| `stages.1.net.0` | conv | 0.035379451 | 0 | 1（逐层标量） | 0.00080405571 | false |
| `stages.1.net.1` | conv | 0.026568696 | 0 | 1（逐层标量） | 0.00056221208 | false |
| `stages.1.net.2` | conv | 0.025780561 | 0 | 1（逐层标量） | 0.00059426081 | false |
| `stages.2.net.0` | conv | 0.038210767 | 0 | 1（逐层标量） | 0.00054271385 | false |
| `stages.2.net.1` | conv | 0.040753977 | 0 | 1（逐层标量） | 0.00036025271 | false |
| `stages.2.net.2` | conv | 0.11887671 | 0 | 1（逐层标量） | 0.00028832979 | false |
| `stages.3.net.0` | conv | 0.26649445 | 0 | 1（逐层标量） | 0.00026400184 | false |
| `stages.3.net.1` | conv | 0.32227527 | 0 | 1（逐层标量） | 0.00022438299 | false |
| `head.0` | linear | 1.1153497 | 0 | 1（逐层标量） | 0.00065067608 | false |
| `head.3` | linear | 0.25333534 | 0 | 1（逐层标量） | 0.00053068571 | false |

## 9. 使用示例（Python + ONNX Runtime）

```python
import numpy as np
import onnxruntime as ort

sess = ort.InferenceSession(
    "grid_cnn_w8a8_pruned_allint8.onnx",
    providers=["CPUExecutionProvider"],
)
x = np.load("../data/X_test.npy").astype(np.float32)  # [N,31,128,32]
logits = sess.run(["logits"], {"input": x})[0]
# 稳定 softmax
z = logits - logits.max(axis=1, keepdims=True)
prob = np.exp(z)
prob = prob / prob.sum(axis=1, keepdims=True)
pred = (prob[:, 1] >= 0.56).astype(np.int64)
```

## 10. 实现检查清单

- [ ] 输入 NCHW：`[N, 31, 128, 32]`，float32  
- [ ] 11 个 Conv：3×3 / pad=1 / stride=1 / **无 bias**，后接 Relu  
- [ ] 4 次 MaxPool：2×2 / stride=2  
- [ ] GlobalAveragePool → Flatten → MatMul(256→256) + Relu → MatMul(256→2)  
- [ ] 全连接 MatMul 权重按 **`y = x @ W.T`** 理解  
- [ ] 输出为 logits，自行 softmax；阈值 **τ=0.56**  
- [ ] 图中无 BatchNorm / Dropout / bias  
- [ ] 若做真 INT8：stem 与 head.3 也要量化；激活用对称 signed INT8（本 ONNX 未包含量化节点）
